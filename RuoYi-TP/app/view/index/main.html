若依管理系统（PHP 移植版）

本项目基于经典若依（RuoYi 4.8.3，Spring Boot 版）逐功能移植，采用 PHP 技术栈复刻其全部管理能力：接口路径、页面交互、响应结构、权限体系与经典版一一对应，前端静态资源原样移植、零改动对接。

可用于网站管理后台、会员中心、CMS、CRM、OA 等 Web 应用场景，亦可作为学习 ThinkPHP 企业级开发的完整参照实现。

当前版本：v{$version} 移植基准：RuoYi v4.8.3


若依原项目

技术选型：

  1. 核心框架：ThinkPHP 8.1。
  2. 运行环境：PHP 8.3。
  3. 模板引擎：think-template。
  4. 数据访问：think-orm（MySQL）。
  5. 会话/缓存：Redis（predis）。
  6. Excel 处理：phpspreadsheet。
  7. 定时任务：microcron + 自研调度器。
  8. 权限体系：注解校验 + RBAC。
功能模块（全部完成）
系统管理
  1. 用户管理（部门树联动、导入导出、分配角色、重置密码）
  2. 角色管理（数据权限、分配用户）与菜单管理（权限标识）
  3. 部门管理（树形）与岗位管理
  4. 字典管理与参数管理（Redis 缓存联动）
  5. 通知公告（summernote 富文本、已读体系）
  6. 操作日志 / 登录日志（查询、导出、清空、账户解锁）
系统监控
  1. 在线用户（Redis 会话实时扫描、强退、自踢防护）
  2. 缓存监控（Redis 前缀枚举、键值查看、批量清理）
  3. 服务监控（CPU/内存/磁盘/PHP 运行环境）与数据监控
  4. 定时任务（Cron 调度、执行日志、账户级并发锁）与调度日志
个人与安全
  1. 登录（验证码、密码错误锁定、记住我）与注册（开关控制）
  2. 个人中心（资料修改、头像裁剪上传、改密强制重登录）
  3. 锁屏/解锁（会话保持软锁）
  4. 数据权限（全部/自定义/本部门及以下/本部门/仅本人）
移植说明

独立数据环境：自用 MySQL 库与 Redis db，与原若依部署完全隔离。

响应契约对齐：code 信封（0/301/500）、驼峰字段、分页结构与经典版一致；同库脚本可直接对照验证。

页面保真：Bootstrap/jQuery 静态资源与页面结构原样移植，操作交互与经典版相同。

行为差异留痕：无法对齐的实现（如 Quartz→自研调度器、ehcache→Redis）全部登记在 specs/deviations.md，共 30 条。

与原若依的会话不互通（存储格式不同），切换系统后需重新登录。

基于 RuoYi 移植，原项目 MIT 协议；本项目仅作学习研究用途。
