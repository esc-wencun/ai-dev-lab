## 动工检查单（每个模块动工前逐条执行）

1. [ ] 读 Java 版 Controller + ServiceImpl + Mapper XML，列出端点总数与 API 清单（方法/路径/参数/返回 JSON），写进该文件夹 `spec.md`
2. [ ] 标注每个端点的 `@PreAuthorize` 权限串与 `@Log` 注解（操作日志 business_type）
3. [ ] 识别特殊行为：唯一性校验文案、admin 保护、级联（部门 ancestors/角色菜单关联）、缓存联动（sys_config/sys_dict）、踢下线
4. [ ] 识别数据权限需求（列表带 dataScope 的）与 Excel 导出列定义（@Excel 注解逐字段抄）
5. [ ] 对照 Python 版同名 spec 的实施记录——踩坑直接复用（各文件夹 spec.md 已预填要点）
6. [ ] 拆 Task 写实该文件夹 `tasks.md`（每 Task 可独立验收）、按写实结果替换细化 `checklist.md`
7. [ ] 与 Java 无法对齐的点登记进 [deviations.md](deviations.md)
